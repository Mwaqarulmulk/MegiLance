🔌 API ENDPOINTS (USE THESE)
================================================================================

Base URL: http://localhost:8000/api/v1/blogs-mongo

1. LIST BLOGS
   GET /
   Parameters: skip=0, limit=10, category=..., keyword=...

2. GET SINGLE BLOG
   GET /{slug}
   Example: /what-is-an-ai-freelancing-platform

3. SEARCH
   GET /search?q={keyword}

4. CATEGORIES
   GET /categories/list

5. BLOG STATS
   GET /stats/overview
