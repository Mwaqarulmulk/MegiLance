# MegiLance 100 Blogs + Generated Images Updated Pack

This ZIP combines the original MegiLance 100 SEO blog article pack with all generated image files currently available in this conversation.

## Included

- 100 SEO blog articles in MDX
- 100 HTML article versions
- 100 JSON-LD schema files
- Master SEO index CSV
- 25-week publishing calendar
- Website SEO notes
- Generated featured images included: 30
- Extra generated composite/raw images

## Image folders

- `featured_images/` contains mapped blog featured images.
- `extra_generated_images/` contains additional generated images from the conversation.

## Manifest

Use `featured_images_manifest.csv` to see which image maps to each blog number, title, and slug.

Important: AI-generated text/logos can contain small visual mistakes. Review images before publishing on the live MegiLance site.
